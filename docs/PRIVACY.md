# Privacy

## The app

- There is no account, no sign-in and no password.
- There are no ads, no analytics, no cookies and no tracking scripts.
- The app loads only its own files from GitHub Pages: the page, its style sheet, its
  scripts, its icons and the day's data file.
- The teams you follow, the stats window you picked (Last 10 or Season) and the last
  tab you opened are saved in your browser's local storage on your device. They never
  leave your device. **Settings > Clear my settings** removes them.
- Links to Daily Faceoff, NHL.com and other sources open those sites in a new tab. Those
  sites have their own privacy policies.
- GitHub hosts the app. GitHub may keep standard web server logs (such as IP address
  and time of request) under the
  [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
  This project cannot see or use those logs.

## The data build

- The build runs on GitHub's servers and reads only public pages and feeds. It uses no
  keys, passwords, accounts or paid services, and the repository holds no secrets.
- The data file holds public sports information only: schedules, scores, standings,
  player and goalie statistics, line combinations, injury notes and the names of the
  reporters who confirmed a starting goalie.
- The repository's tests scan every file for email addresses, local file paths and key
  formats before any change is accepted.
